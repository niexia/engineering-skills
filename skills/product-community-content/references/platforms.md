# Platform rules

Limits change. Verify the current limit in the composer or the subreddit rules
during the run and write down what was verified.

## Shared

- One angle per run, three native drafts. Do not copy one draft across platforms.
- Disclose that the author builds the product wherever the community expects it.
- Quote reviews verbatim and short; attribute platform and date.
- No invented numbers, users, ratings, urgency or engagement bait.
- Put links where they read naturally. Do not hide affiliation behind a neutral
  tone or a fake user voice.
- Language: English on X and Reddit, Chinese on Xiaohongshu, unless the profile
  says otherwise.

## X

| Item | Guidance |
| --- | --- |
| Length | 280 characters, counting the link's 23-character t.co form |
| Threads | 2–4 posts, one idea each; the first post must stand alone |
| Hashtags | 0–2, only ones the audience actually follows |
| Images | 1600×900 preferred, up to 4, with alt text |
| Links | A link in the first post can reduce reach; a reply is acceptable |
| Tone | Plain, specific, first person, no motivational filler |

Write the change, who it helps and what is new: one claim, one proof.
Avoid announcement boilerplate, emoji chains and "RT if" requests.

## Xiaohongshu

| Item | Guidance |
| --- | --- |
| Title | 20 characters or fewer, concrete, no clickbait |
| Body | About 1000 characters or fewer, short lines, scannable |
| Images | 3–9 is a good range (up to 18 allowed); cover 3:4 at 1080×1440; following images 1:1 or 3:4 |
| Topics | 5–8 relevant topics |
| Links | External links and contact details are restricted; describe where to find it instead |
| Tone | Personal, experience first, honest about being the maker |
| Claims | Avoid superlatives and absolute claims that advertising rules restrict |

Write the situation, what changed in real use, one concrete detail. Product
comparisons must be factual and about the author's own product.
Avoid emoji stuffing, promises such as "永久免费" unless literally true, invented
before/after results, and undisclosed paid promotion.

## Reddit

| Item | Guidance |
| --- | --- |
| Title | 300 characters or fewer; state the change or the question, no marketing voice |
| Body | Markdown, value first, author disclosure, no emoji wall |
| Subreddit | Take it from the profile and read that subreddit's current rules and self-promotion policy in this run |
| Links | One link, after context; plan comment participation, not just the post |
| Flair | Required by many subreddits; name the intended flair |
| Tone | Peer to peer, matter of fact, comfortable with criticism |

Write why it was built, the problem, what is different, what it does not do.
Avoid identical cross-posts, link-only posts and ignored rules. When a subreddit
restricts self-promotion, draft the post for a community where it fits or hand
the user a comment-style option instead. If the rules page does not load
automatically, do not guess: mark the rules unverified and ask the user to
confirm flair and self-promotion policy in the browser before posting.

## Images

| Platform | Size | Reason |
| --- | --- | --- |
| X | 1600×900 (16:9) | timeline and card crop |
| Xiaohongshu | 1080×1440 (3:4) | feed cover |
| Reddit | 1200×630 (1.91:1) | link and post preview |

Screenshots with small text read better letterboxed on a clean background than
cropped. Keep one idea per image, and do not show personal data, private document
titles or notification banners.
